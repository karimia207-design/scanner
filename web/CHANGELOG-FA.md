# تغییرات نسخه ۷٫۷٫۱

## جداسازی پایش از مجوز ورود
1. `surveillanceEligible` مستقل از `executionEligible` محاسبه می‌شود.
2. نامزدهای دارای داده ۱H/۴H معتبر، Snapshot هم‌تراز، قیمت تازه، محاسبه ریسک معتبر و حد ضرر ساختاری در صف پایش قرار می‌گیرند؛ حتی اگر R/R، حجم، اسپرد یا تأیید هزینه‌ها هنوز مجوز ورود ندهد.
3. داده ۱۵m و ۵m برای نامزدهای واجد شرایط پایش دریافت و بررسی می‌شود. پایش فنی، مجوز ورود ایجاد نمی‌کند.
4. `technicalEntryTriggerDetected` از `entryTriggerConditionsMet` تفکیک شده است؛ ماشه تکنیکی ممکن است شناسایی شود اما تا عبور از تمام شروط اقتصادی و ریسک، هشدار ورود صادر نمی‌شود.

## رتبه‌بندی قابلیت معامله
1. `Tradeability Score` مستقل از `Opportunity Score` افزوده شد.
2. امتیاز قابلیت معامله از حجم ۲۴ساعته، اسپرد، R/R خالص، فضای تا مقاومت و فاصله حد ضرر تشکیل می‌شود.
3. `rankingScore` ترکیبی برای مرتب‌سازی صف پایش است؛ هیچ‌یک از این امتیازها احتمال برد یا مجوز ورود نیستند.

## صف پایش چندنمادی
1. صف منصفانه بر پایه قدیمی‌ترین زمان پایش هر نماد ساخته می‌شود.
2. امتیاز قابلیت معامله و کشف فقط برای شکستن تساوی اولویت به‌کار می‌روند.
3. Cooldown مستقل هر نماد و محدودکننده مشترک OHLC حفظ می‌شوند تا فشار غیرضروری به API وارد نشود.
4. تحلیل روزانه اختیاری خارج از صف اصلی ۵m/۱۵m زمان‌بندی می‌شود.

## شروط ورود و ریسک
- حداقل R/R خالص، تأیید کارمزد و لغزش، حداقل حجم، سقف اسپرد، اعتبار Snapshot، حد ضرر و کندل‌های بسته‌شده بدون تسهیل باقی مانده‌اند.
- تأیید پایدار ماشه و عدم ارسال سفارش خودکار حفظ شده‌اند.
- نامزدهای داده کهنه، Snapshot نامنسجم، ریسک نامعتبر، بازار بسته و فاصله حد ضرر بیش از ۸٪ وارد صف پایش نمی‌شوند.

## تشخیص و گزارش‌گیری
خروجی Diagnostics به نسخه ۱۳ ارتقا یافته و وضعیت صلاحیت پایش، صلاحیت ورود، امتیاز قابلیت معامله، موانع پایش، موانع ورود و تشخیص ماشه تکنیکی را جداگانه ثبت می‌کند.

## محدودیت‌ها
این نسخه آزمون‌های ایستای کد و آزمون‌های واحد را می‌گذراند؛ آزمون چندساعته زنده بازار، آزمون بلندمدت نرخ خطای API و بک‌تست خارج از نمونه همچنان لازم است. هدف ۵ فرصت روزانه تضمین نمی‌شود و شروط ورود برای پرکردن سهمیه کاهش نمی‌یابند.
