# دارایی‌های وب نوبیتکس ۷٫۶٫۰

این پوشه شامل صفحات و اسکریپت‌های رابط وب/موبایل است که توسط `scripts/build-web.mjs` برای Capacitor در `www/` کپی می‌شوند. مستندات اصلی ساخت، keystore پایدار، نصب و محدودیت‌های آزمون در فایل `../README-FA.md` قرار دارد.


نسخه اندروید همراه این سورس برای Build اولیه به‌صورت Debug تنظیم شده و برای تولید APK آزمایشی به keystore یا Secret امضا نیاز ندارد.
