اتصال حساب نوبیتکس با API Key

هر دو کلید عمومی و خصوصی مربوط به یک API Key را وارد کنید. برنامه ابتدا درخواست امضاشده خواندن کیف‌پول‌ها را آزمایش می‌کند و فقط پس از پاسخ موفق، اتصال را فعال و اطلاعات لازم را روی همین دستگاه ذخیره می‌کند.

مجوز کلید در پنل نوبیتکس را فقط روی READ قرار دهید. در APK، کلیدها در Android Keystore نگهداری می‌شوند. در نسخه وب HTTPS، کلید خصوصی خام ذخیره نمی‌شود و ابتدا به کلید امضای Ed25519 غیرقابل‌استخراج Web Crypto تبدیل و در IndexedDB محلی همان مرورگر نگهداری می‌شود؛ این روش معادل Android Keystore سخت‌افزاری نیست. اتصال مستقیم وب به مجازبودن CORS از طرف نوبیتکس وابسته است. این ماژول فقط GET /users/wallets/list را اجرا می‌کند و هیچ سفارش، معامله یا برداشتی نمی‌فرستد.
مجوز API در پنل نوبیتکس باید فقط READ باشد. کلیدهای عمومی و خصوصی باید متعلق به یک جفت باشند.
