# سامانه هوشمند نوسان‌گیری نوبیتکس – نسخه ۶.۳ (پروژه کامل منبع)

این بسته بر مبنای فایل نسخه ۶.۲ ارسالی شما تهیه شده است. موتور تحلیل قبلی حفظ شده و اتصال خواندنی حساب نوبیتکس به آن اضافه شده است.

## امکانات نسخه ۶.۳

- حفظ رابط و موتور تحلیل نسخه ۶.۲.
- اتصال اختصاصی حساب نوبیتکس فقط با مجوز `READ`.
- ورود یک‌باره هر دو مقدار Public Key و Private Key مربوط به یک جفت API.
- آزمایش اتصال از طریق `GET /users/wallets/list` پیش از ذخیره کلیدها.
- امضای درخواست با Ed25519 و سه هدر `Nobitex-Key`، `Nobitex-Signature` و `Nobitex-Timestamp`.
- ذخیره محلی کلیدها از طریق افزونه Secure Storage؛ در Android داده با AES-GCM رمزگذاری و کلید رمزگذاری در Android Keystore نگهداری می‌شود.
- دریافت و نمایش موجودی کیف‌پول‌ها و امکان حذف کلیدها از همین دستگاه.
- بدون سرور، فضای ابری، Firebase یا FCM.

## نکته درباره ساختار پروژه

این ZIP یک پروژه کامل منبع Capacitor است. پوشه `android/` داخل ZIP قرار نگرفته، چون Capacitor باید آن را متناسب با محیط توسعه و نسخه نصب‌شده ابزارهای Android ایجاد کند. اسکریپت `setup:android` این کار را انجام می‌دهد؛ بنابراین لازم نیست فایل‌های اندروید را دستی بسازید.

## پیش‌نیازها برای ساخت APK

- Node.js نسخه ۲۲ یا جدیدتر و npm.
- Android Studio سازگار با Capacitor 8.
- JDK 21 و Android SDK نصب‌شده از طریق Android Studio.
- اینترنت هنگام اولین نصب وابستگی‌های npm و همگام‌سازی Gradle.

## روش ساده در Windows

۱. ZIP را استخراج کنید.
۲. مطمئن شوید Android Studio و JDK 21 نصب هستند.
۳. روی فایل `SETUP-ANDROID-WINDOWS.bat` دوبار کلیک کنید.
۴. اسکریپت وابستگی‌ها را نصب می‌کند، ساختار Android را در صورت نبودن ایجاد می‌کند، پل بومی را می‌سازد، پروژه را همگام و Android Studio را باز می‌کند.
۵. در Android Studio از مسیر **Build > Build Bundle(s) / APK(s) > Build APK(s)** خروجی APK بسازید.

## روش خط فرمان

در ترمینال و در پوشه اصلی پروژه اجرا کنید:

```bash
npm install
npm run verify:source
npm run setup:android
npm run open:android
```

پس از تغییر فایل‌های `www`، برای انتقال تغییرات به پروژه Android اجرا کنید:

```bash
npm run sync:android
```

## محل فایل‌ها

- `www/` فایل‌هایی است که در APK بارگذاری می‌شوند.
- فایل‌های هم‌نام در ریشه برای انتشار وب/GitHub Pages نگهداری شده‌اند.
- `src/native-bridge.js` پل واقعی Capacitor است و با esbuild به `www/native-bridge.js` تبدیل می‌شود.
- `nobitex-account.js` منطق اتصال، امضای Ed25519 و درخواست فقط‌خواندنی را دارد.
- `capacitor.config.json` شناسه برنامه و webDir را مشخص می‌کند.
- `package.json` وابستگی‌ها و فرمان‌های ساخت را تعریف می‌کند.

## اتصال API نوبیتکس

در پنل نوبیتکس یک کلید جداگانه بسازید و فقط `READ` را فعال کنید. `TRADE`، `WITHDRAW` و سایر مجوزها لازم نیستند. کوتاه‌ترین تاریخ انقضای مناسب را انتخاب کنید. با توجه به تغییرپذیری IP اینترنت موبایل، IP whitelist را فقط وقتی فعال کنید که IP خروجی ثابتی دارید.

پس از نصب APK:

۱. برنامه را باز کنید.
۲. در بخش «اتصال امن به حساب نوبیتکس» گزینه «ورود یک‌باره کلید API» را بزنید.
۳. Public Key و Private Key همان جفت را وارد کنید.
۴. گزینه «آزمایش اتصال و ذخیره امن» را انتخاب کنید.
۵. فقط پس از پاسخ موفق نوبیتکس، کلیدها در فضای امن دستگاه ذخیره می‌شوند. دفعات بعد ورود دوباره لازم نیست.

کلید خصوصی را در GitHub، فایل HTML، ZIP، فایل پشتیبان، گزارش خطا یا این گفتگو قرار ندهید. کلید واقعی در این بسته وجود ندارد.

## مرزهای عملکرد و امنیت

- ماژول حساب در این نسخه فقط درخواست `GET /users/wallets/list` اجرا می‌کند. مسیرهای ایجاد سفارش، تغییر سفارش، لغو سفارش و برداشت وجه در ماژول اتصال حساب پیاده‌سازی نشده‌اند.
- مجوز `READ` در پنل نوبیتکس باید جداگانه انتخاب شده باشد. کد برنامه جایگزین محدودیت مجوز سمت صرافی نیست.
- کلید خصوصی هنگام ساخت امضا برای مدت کوتاه در حافظه فرایند برنامه استفاده می‌شود؛ رمزگذاری در حالت سکون، در برابر دستگاه روت‌شده، بدافزار دارای دسترسی سیستمی یا دیباگ مخرب تضمین مطلق ایجاد نمی‌کند.
- حذف کلید از برنامه فقط نسخه ذخیره‌شده در این گوشی را پاک می‌کند؛ برای ابطال کلید باید آن را از پنل نوبیتکس حذف کنید.
- درخواست API به اینترنت و دسترسی از IP مجاز نوبیتکس نیاز دارد. داده‌ها و موجودی حساب بدون اینترنت قابل دریافت نیستند.
- نسخه وب/GitHub Pages به‌دلیل نداشتن Android Keystore اتصال حساب را فعال نمی‌کند؛ اتصال اختصاصی فقط در APK ساخته‌شده فعال است.
- این نسخه شامل Foreground Service، پایش دائمی پس‌زمینه و اعلان بومی فرصت‌های ورود نیست. آن قابلیت‌ها توسعه جداگانه‌ای هستند و در این ZIP ادعا نمی‌شوند.
- این بسته سورس قابل Build است، نه APK امضاشده. برای ساخت APK به Android Studio و SDK محلی نیاز دارید.

## ساخت APK بدون نصب ابزار توسعه روی رایانه

برای ساخت APK با زیرساخت GitHub و بدون نصب Node.js یا Android Studio روی رایانه خود، راهنمای `GITHUB-ACTIONS-ANDROID-FA.md` را دنبال کنید. Workflow در مسیر `.github/workflows/build-android-apk.yml` قرار دارد. پس از Push به شاخه `main` یا `master`، از زبانه Actions فایل APK را از قسمت Artifacts دریافت کنید.
