# ساخت APK اندروید (بدون نصب Android Studio)

1. در github.com یک مخزن (Repository) جدید بسازید (می‌تواند Private باشد).
2. محتوای همین پوشه را در آن آپلود کنید (Add file ← Upload files). پوشه مخفی `.github` هم باید آپلود شود.
3. به تب Actions بروید و workflow با نام «Build Android APK» را اجرا کنید (Run workflow). حدود ۵ تا ۸ دقیقه طول می‌کشد.
4. پس از پایان، در صفحه اصلی مخزن، بخش Releases ← «Nobitex Scanner (latest)» فایل `Nobitex-Scanner.apk` را دارد. این لینک دانلود مستقیم است و آن را روی گوشی باز کنید.
5. در گوشی «نصب از منابع ناشناس» را برای مرورگر یا فایل‌منیجر مجاز کنید و نصب کنید.

نکته‌ها:
- APK با کلید debug امضا می‌شود؛ برای استفاده شخصی مناسب است، نه انتشار در Google Play.
- Private بودن مخزن یعنی لینک Release فقط برای حساب شما کار می‌کند. برای لینک عمومی، مخزن را Public کنید.
- هر بار فایل `www/index.html` را عوض و commit کنید، APK جدید ساخته می‌شود.
