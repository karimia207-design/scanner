# سامانه هوشمند نوسان‌گیری نوبیتکس ۷٫۷٫۱

نسخه وب/PWA و پوسته اندروید Capacitor با موتور چنداستراتژی و جداسازی پایش از مجوز ورود.

## موتور فرصت‌یابی
- چهار الگوی خرید Spot: ادامه روند، اصلاح و بازگشت، برگشت از کف محدوده و شکست/بازآزمایی.
- `Opportunity Score` برای کشف و اولویت‌بندی الگوهاست؛ احتمال برد یا مجوز ورود نیست.
- `Tradeability Score` جداگانه حجم، اسپرد، R/R خالص، فضای تا مقاومت و فاصله حد ضرر را رتبه‌بندی می‌کند.
- نامزد واجد شرایط پایش می‌تواند پیش از تکمیل شروط اقتصادی در صف بررسی ۱۵m/۵m قرار گیرد؛ این وضعیت مجوز معامله نیست.
- مجوز ورود فقط پس از عبور از تمام دروازه‌های سخت، تأیید کندل بسته‌شده، اسپرد، حجم، هزینه‌های تأییدشده، صحت Snapshot و حداقل R/R خالص صادر می‌شود.

## ساخت اندروید
1. کل ZIP را در ریشه Repository بارگذاری کنید و ساختار `.github/workflows` را حفظ کنید.
2. GitHub Actions را فعال کنید.
3. Workflow با نام `Build Nobitex Android APK` را اجرا کنید.
4. Artifact `nobitex-v7.7.1-android-debug-apk` را دریافت کنید.

Debug APK برای آزمون است؛ برای توزیع عمومی، نسخه Release با کلید امضای اختصاصی تولید شود.

## اجرای مرورگری
تمام فایل‌های بسته مرورگری باید کنار `index.html` در ریشه GitHub Pages قرار گیرند. پایش مرورگری به بازماندن تب و اجرای فعال JavaScript وابسته است؛ Service Worker به‌تنهایی بازار را اسکن نمی‌کند.

## محدودیت‌ها و ایمنی
- هدف ۵ فرصت در روز معیار سنجش است، نه تضمین سود یا صدور اجباری سیگنال. در بازار نامناسب، صفر فرصت آماده ورود می‌تواند نتیجه صحیح باشد.
- هیچ سفارش واقعی یا خودکار ارسال نمی‌شود.
- عمق کامل دفتر سفارش برای تمام بازارها در امتیاز سراسری استفاده نمی‌شود؛ Order Book Imbalance به‌عنوان قابلیت کامل اجراشده ادعا نمی‌شود.
- داده ۵m/۱۵m تنها برای نامزدهای دارای داده پایه معتبر، Snapshot هم‌تراز، مظنه تازه و ریسک ساختاری معتبر پایش می‌شود.
- شمارنده روزانه محلی است و بین مرورگرها یا دستگاه‌ها همگام‌سازی نمی‌شود.
