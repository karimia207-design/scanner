# نوبیتکس ۷٫۵٫۰ | بسته انتشار GitHub Pages

## تغییرات این نسخه
نسخه ۷٫۵٫۰ علاوه بر جدول بازار، یک موتور مستقل برای شناسایی فرصت ورود دارد. این موتور همه نمادهای یونیورس بازار را بررسی می‌کند و نتیجه آن به جستجو، فیلترهای نمایشی یا واچ‌لیست دستی وابسته نیست.

### منطق فرصت‌یابی
1. **روند پایه:** شروط موجود ۱ساعته و ۴ساعته، کیفیت داده، نقدشوندگی، اسپرد، حمایت/مقاومت و R/R خالص بررسی می‌شوند.
2. **زمینه:** برای نمادهایی که شروط پایه را گذرانده‌اند، داده ۱۵ دقیقه‌ای دریافت و EMA9/EMA20، RSI و جایگاه بسته‌شدن قیمت کنترل می‌شود.
3. **ماشه:** کندل ۵ دقیقه‌ای بسته‌شده باید شکست سقف ۲۰ کندل قبل با حجم حداقل ۱٫۱۵ برابر میانگین، یا پولبک معتبر با حفظ سطح و حجم حداقل ۰٫۸ برابر میانگین را نشان دهد. RSI و EMAهای ۵ دقیقه‌ای نیز کنترل می‌شوند.
4. **عدم تعقیب قیمت:** قیمت خرید جاری باید نزدیک سطح ماشه باشد و بیش از ۰٫۸٪ بالاتر از آن قرار نگرفته باشد.
5. **کارت نهایی:** ورود مرجع/محدوده مجاز، هدف ساختاری، حد ضرر، R/R خالص، اندازه و ارزش موقعیت، زیان برآوردی در حد ضرر، حمایت/مقاومت، حجم شکست و شرایط ابطال نمایش داده می‌شود.

نمادهایی که تمام شروط را ندارند در بخش بازشونده «نمادهای در انتظار تکمیل شروط» همراه با دلیل دقیق عدم تأیید و سطح ماشه احتمالی نمایش داده می‌شوند. این موتور از فیلترهای دستی و واچ‌لیست مستقل است.

## فایل‌های بسته
- `index.html`: هسته سامانه، موتور تحلیل و رابط وب/موبایل
- `nobitex-account.js`: اتصال خواندنی API اختصاصی حساب نوبیتکس
- `native-bridge.js`: fallback وب؛ پل واقعی Android در این بسته موجود نیست
- `manifest.webmanifest` و `sw.js`: PWA و کش پوسته
- `icon.svg`: آیکون
- `VERSION.txt`، `README-FA.md` و `CHANGELOG-FA.md`: نسخه و مستندات

## بارگذاری در GitHub Pages
1. ZIP را استخراج کنید.
2. تمام فایل‌های داخل پوشه `nobitex-v7.5.0` را مستقیماً در ریشه Repository بارگذاری و فایل‌های هم‌نام قبلی را جایگزین کنید.
3. در GitHub به Settings → Pages بروید و شاخه انتشار/پوشه ریشه را انتخاب کنید.
4. برنامه را با HTTPS باز کنید.
5. برای نصب روی گوشی سامسونگ، صفحه را در Chrome باز کنید و از منوی مرورگر گزینه Install app یا Add to Home screen را انتخاب کنید. پس از انتشار، یک بار صفحه را Refresh کنید؛ در صورت ماندن نسخه قبلی، داده‌های سایت و Service Worker مربوط به دامنه را پاک و دوباره نصب کنید.

## موبایل در برابر APK بومی
در بسته فعلی، نسخه وب و PWA یک کد مشترک واکنش‌گرا دارند. کنترل‌های اصلی، فیلترها، گزارش‌ها، نمودار، تنظیمات، دفتر معاملات و کارت‌های فرصت در صفحه موبایل قابل دسترسی‌اند. این ZIP سورس Android/Capacitor یا APK نیست. برای اعمال تغییر در لایه Native، پروژه اصلی Android/Capacitor باید در اختیار باشد.

## API و ایمنی
- برای API اختصاصی نوبیتکس فقط مجوز READ لازم است؛ مجوز معامله و برداشت را فعال نکنید.
- کلیدها را در GitHub یا فایل‌های پروژه قرار ندهید.
- این سامانه سفارش خودکار ثبت نمی‌کند.

## نکته ریسک
آستانه‌های ماشه ۱۵m/۵m و حجم شکست، قواعد تحلیلی هستند و هنوز در این بسته بک‌تست یا اعتبارسنجی آماری مستقل نشده‌اند. کارت «ورود تأیید شد» را به‌عنوان تأیید الگوریتمی شروط بخوانید، نه تضمین سود. قیمت بازار، عمق سفارش و کارمزد را پیش از معامله واقعی دوباره کنترل کنید.

## آزمون‌های انتشار
آزمون نحوی JavaScript، اعتبار ساختار HTML، آزمون توابع ارزیابی ماشه با داده ساختگی و صحت ZIP پیش از ارائه انجام شده‌اند. اتصال زنده API نوبیتکس و رفتار واقعی در گوشی فیزیکی از این محیط قابل آزمایش نیست.
