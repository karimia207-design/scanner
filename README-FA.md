# نسخه وب و موبایل نوبیتکس ۷٫۶٫۰

`index.html` نسخه دسکتاپ و `mobile-index.html` نسخه موبایل است. همه فایل‌های پوشه را در ریشه GitHub Pages بارگذاری کنید.

## نکات مهم
- شروط ورود و ریسک قبلی حفظ شده و وضعیت آماده نیازمند دو مظنه تازه با حداقل فاصله ۶ ثانیه است.
- Snapshot واحد و شناسه‌دار برای تصمیم، مودال و Diagnostics استفاده می‌شود.
- افزودن دستی نمادهای USDT فعال و افزودن نتایج فیلتر به واچ‌لیست فراهم است.
- نسخه وب فقط تا وقتی مرورگر اجازه اجرای تب را بدهد پایش می‌کند؛ پس از بستن مرورگر، اجرای دائمی تضمین نمی‌شود.
- CSP فقط Originهای مجاز در فایل HTML را می‌پذیرد. برای پروکسی اختصاصی، Origin دقیق را به `connect-src` اضافه کنید. `style-src 'unsafe-inline'` به‌علت سبک‌های پویا باقی مانده است.
- بک‌تست به تاریخچه محلی محدود است و ماشه تاریخی ۵/۱۵ دقیقه‌ای، اسپرد تاریخی و عمق دفتر سفارش را ندارد.
- کارمزد/لغزش پیش‌فرض و حداقل حجم باید با حساب واقعی تطبیق و صریحاً تأیید شوند؛ تا آن زمان آلارم ورود نهایی صادر نمی‌شود.
